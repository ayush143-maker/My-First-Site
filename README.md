# My-First-Site

A beginner-friendly website created while learning HTML and CSS. It brings together About Me, First Project, What I Learned, and Contact sections on one page.

## Open the website

No package installation is needed. Open `index.html` in a browser, or start a local server:

    python -m http.server 8000

Visit http://localhost:8000.

## Learning by editing

Try changing the text, colours, spacing, or section order in `index.html` to see how the page structure and styling work together.
